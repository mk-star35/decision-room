## 구조 변경

- **Setup B9 As of Date** 신설 (기본값 `=TODAY()`). Accounts Tracker / Savings / Debt가 이 날짜까지만 집계.
- **반복거래 블록 31행 → 61행**. 카테고리 입력 여유가 2행 → 39행 (20~58행).
- **Manual Log 헬퍼 M:AZ 40열 삭제** → `_Lists` AA/AB/AC 3열(카테고리별 정렬 목록)로 대체.
- **Payments 재생성**: 행마다 반복되던 날짜식을 숨김 보조열 `N` 하나로 통합, 카테고리 조회는 항목당 1회.
- 부채 3건 → 10건, 순자산 자산 12줄 / 부채 11줄, Annual에 YEAR TOTAL·MONTHLY AVG 추가.
- 휘발성 `OFFSET` 이름(`PayDates`)을 계산 수식에서 전부 평범한 범위로 교체(드롭다운 원본으로만 유지).
